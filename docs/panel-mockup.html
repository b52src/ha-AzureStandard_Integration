Azure Standard integration · v0.1.4
📋 Phase Roadmap
✅ 1–10

Core Integration v0.1.0

Scaffold, public drop/cutoff sensors, account login config flow, order sensors, shopping list sensors, product discovery engine, per-product sensor groups, options flow, account sensors, HACS polish.

✅ 11

Sidebar Panel — Web Component v0.1.1

ES6 Web Component registered via panel_custom. Reads all sensor.azure_standard_* entities live from hass.states. Renders Drop & Cutoff, Active Order, Lists, and Products sections.

✅ 12 / 12b

Four-Tab Redesign + Deep-Links v0.1.2 / v0.1.3

Migrated to async_register_static_paths. Four-tab layout with ↻ refresh button. Real deep-link URLs for lists, orders, and product pages on azurestandard.com.

✅ 13

Price History Sparklines v0.1.4

Rolling price history (up to 12 samples) accumulated in the coordinator. Inline 40×20 px SVG sparklines in the Products tab "Price" column. In-memory only — resets on HA restart.

⭐ 14 — NEXT

Panel Config UI — Show/Hide Tabs v0.1.5

Let users choose which tabs are visible, persisted across restarts via HA's storage API.

  • Gear icon in panel header opens an inline settings drawer
  • Toggle checkboxes for Lists, Products, and Account tabs
  • Settings written to .storage/azure_standard_panel_config via hass.callWS
  • Prefs loaded on first render — default: all tabs visible
⬜ 15

Sidebar Notifications Badge v0.1.6

Show a reorder-due count on the sidebar icon so users see how many products need reordering at a glance.

  • Count products where reorder_due = "true"
  • Update panel registration with a badge overlay or icon_color
  • Clears when all reorder-due products are ordered
⬜ 16

Automation Blueprints v0.1.7

Pre-built HA automation blueprints shipped with the integration.

  • Cutoff approaching — notify N days before next cutoff
  • Order window opened — alert when order_window_open turns on
  • Reorder reminder — daily check for products with reorder_due = true
  • Blueprints in blueprints/azure_standard/, auto-imported on setup
